# 奶蛙桌宠安全审查记录

审查日期：2026-10-23（Asia/Shanghai）。

## 当前结论

对本次编写的 C# / WPF 桌宠代码进行静态检查后，未发现联网、下载并执行外部代码、读取账号密码、全局键盘监听、注册开机启动或执行系统命令的实现。该结论属于源码与本机运行状态检查，不等同于杀毒引擎已判定无毒。

## 来源与构建

- 奶蛙应用由本地 C# 源码编译，运行的不是第三方仓库提供的成品奶蛙 EXE。
- 使用了第三方仓库的 PNG/GIF 动画、ICO 图标与语音；来源和固定提交列在使用说明中。
- 应用项目没有第三方 NuGet PackageReference；运行使用随包提供的微软 .NET / Windows Desktop 运行时。
- 素材处理时曾使用通过 `imageio-ffmpeg` 0.6.0 Python 包取得的 FFmpeg 工具。该工具只用于制作阶段，不随桌宠程序运行。

## 文件与系统访问

- 正常运行在当前用户 `%LOCALAPPDATA%\NaiwaPet` 保存位置、音量和置顶设置，并缓存嵌入的 WAV 音频。
- `--self-test` 模式在明确指定的输出目录保存检查报告和桌宠窗口渲染图。
- 鼠标事件由桌宠自身窗口处理；没有全局键盘钩子，也没有键盘内容记录代码。
- 本次检查运行中的 v1.1.0 进程时，TCP 连接与 UDP 端点均为 0。这是当时的快照，不是所有历史网络行为的证明。
- 原 v1.1.0 EXE 的 SHA-256 为 `D4CA8BD9323D5CF869D3DC1D5A2632D05BFC84BCC9EF5501028C19162840E99E`，与先前保存的运行验证记录一致。最终构建的对应哈希另见验证结果文件。
