# 本次审查

日期：2026-10-23。范围：奶蛙 Windows 桌宠源码、嵌入素材、构建方式、交互状态与运行检查。

## 已修复

- P2：语音自然结束会调用取消操作的方法，清除仍按住的鼠标状态。用户按住奶蛙等待台词结束后无法继续拖动。现在自然完成仅结束播放并回到待机，保留按下状态；新增状态测试与两项运行回归检查。
- P2：窗口构造阶段的资源、文件或权限异常发生在 UI 事件循环之前，原先可能直接退出。现在启动阶段捕获错误并提示；自检模式保存失败报告。读取设置遇到权限拒绝时回到默认设置。
